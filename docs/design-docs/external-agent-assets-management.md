# 外部 Agent 资产统一版本治理设计

- 状态：adopted
- 初次记录：2026-09-09

## 设计决策

采用“外部版本化权威来源 + 仓库内完整快照 + lock 内容校验 + 宿主规则保留项目差异”：

- `tisfeng/skills` 统一维护六个通用 Skill 与四个 Codex 子代理，二者使用同一个发布 tag。
- 受管快照使项目可离线审查和复现；lock 记录来源和内容哈希，防止本地静默漂移。
- 项目特有的 Action 事件、外部写入和打包边界继续由宿主文档定义，不通过 fork 通用 Skill 实现。
- `fireworks-tech-graph` 未被本项目采用；若未来需要，应作为独立授权任务评估版本、许可证、
  体积与运行时依赖。

现行操作规则以 [`../agents/README.md`](../agents/README.md) 为准；本文只解释设计理由。
