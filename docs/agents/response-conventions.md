# 回复与交付表达

本文件只规定面向用户的语言和结果表达；请求来源与内部任务模式见
[`request-boundary.md`](request-boundary.md)，Git 提交后的完整报告见
[`git-workflow.md`](git-workflow.md)。

## 回复语言

回复时匹配用户使用的语言。如果当前请求使用英文，则用英文回复；否则遵循请求中已经使用的语言。

## 交付物表达

交付物标题、commit message、PR 描述和代码注释优先描述实际完成的正向行为：

- 描述新增、修复、保留或验证的内容。
- 附件中的无关对象、被排除方案或反例不进入标题和主要结论。
- 只有在解释兼容性、风险或验证结果时，才引用被排除内容。
- 不从附件或引用材料复制与当前目标无关的名称、要求或行动。
- 请求来源判断和任务模式分类属于内部执行过程；面向用户的回答直接交付所请求的结果。
  除非解释边界、风险或未验证项确有必要，否则不复述内部来源判断、包装文本或内部标签。
